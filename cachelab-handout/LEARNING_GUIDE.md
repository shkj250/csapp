## 热身：手算一个小缓存

设 `s=1, E=1, b=2`：2 组，每组 1 行，每块 4 字节。纸上从空缓存开始访问 `0x0, 0x1, 0x8, 0x0`，逐步记录组号、tag、有效位和结果。

过关标准：能解释同块访问和同组冲突的区别；知道 miss 不总意味着 eviction。

<details>
<summary>热身自检：先手算再打开</summary>

这四次是 miss、hit、miss eviction、miss eviction。`0x0` 与 `0x1` 属于同块；`0x8` 与 `0x0` 映射同一组但 tag 不同。

</details>

## 关键知识

`s` 是组索引位数，组数 `S=2^s`；`E` 是每组行数；`b` 是块内偏移位数，块大小 `B=2^b`。地址由高到低分为 **tag | set index | block offset**。别把参数值直接当组数或块大小。

LRU（最近最少使用）依据最近访问，命中也会更新顺序。读取 trace 时，`I` 忽略，`L`、`S` 各访问一次，`M` 表示先读后写的两次访问；以讲义“不跨块访问”的假设处理大小字段。

## 阶段 1：先做能解释的模拟器

分三步实现：参数与 trace 解析 → 命中与空行填充 → 满组驱逐与 LRU。每步在纸上预测，再与参考程序对照。地址类型要能容纳 trace 的地址；最后调用原接口 `printSummary`。

```sh
make csim
./csim-ref -v -s 2 -E 1 -b 4 -t traces/dave.trace
./csim -v -s 2 -E 1 -b 4 -t traces/dave.trace
./test-csim
```

过关标准：逐条行为与参考相符，原模拟器测试通过；能设计一个区分 LRU 和 FIFO 的访问序列。仅最后计数相同还不能说明中间状态正确。

<details>
<summary>提示 1：统计错了，从哪里找</summary>

先定位第一条分歧，检查地址拆分，再检查有效位，最后检查驱逐选择。若只在 `M` 上出错，手算同一地址连续两次访问：第二次应能找到刚访问的块。

</details>

<details>
<summary>提示 2：E=1 对了，E>1 却错</summary>

检查是否搜索了组内所有行；是否优先填空行；命中时是否更新最近访问记录。构造“A、B、A、C”映射同组的实验，比较不同替换策略留下谁。

</details>

## 阶段 2：转置正确，再讨论 misses

在纸上转置一个 2×3 的矩阵：`A` 有 `N` 行 `M` 列，`B` 有 `M` 行 `N` 列。确认读写下标与边界，再实现自己的正确基线。

本地目标缓存是 1KB、直接映射、块大小 32 字节。一个块能容纳 8 个 4 字节 `int`；连续读 A 不保证对 B 的写入连续。

```sh
make
./test-trans -M 32 -N 32
./test-trans -M 64 -N 64
./test-trans -M 61 -N 67
```

过关标准：三种尺寸都正确；保存初始 misses，作为后续基线。需要 Valgrind 才能完成访存跟踪。

## 阶段 3：分块、冲突与边缘

先在 32×32 探索分块，再在 64×64 分析组冲突，最后处理 61×67 的不完整边缘。画出同一时刻活跃的 A、B 块映射到哪些组，而不是只尝试不同块尺寸。

每次只改一个因素，记录三个尺寸的正确性和 misses。保留描述字符串 `Transpose submission`；遵守最多 12 个局部 `int` 的规则，辅助调用的栈上局部变量也计入约束；不得修改 A、使用数组临时缓存或 malloc。

<details>
<summary>提示 3：32×32 很好，64×64 反而慢</summary>

行跨度变了，组映射也会变。检查 A 与 B 的活跃块是否互相驱逐，尤其是读后写再读的时刻。考虑调整访问顺序和数据暂存位置，先证明它减少哪类冲突。

</details>

## 完整验收与进阶

模拟器跑完整 `test-csim`；转置跑全部三个尺寸，同时检查规则。当前 `driver.py` 是 Python 2，若环境有兼容解释器，可用 `python2 driver.py`；没有时分别运行上述测试，不把部分测试称为原综合评分已通过。

本地评分脚本的满分阈值分别是 300、1300、2000 misses。阈值用于最终性能目标，不替代正确性或人工规则检查；具体课程以课程评分为准。

进阶：把某种冲突缩成两组地址的反例；改变缓存 `E` 或块大小，预测优化效果后再模拟。能说明为什么某策略在另一缓存模型下失效，比背一个分块尺寸更有价值。
