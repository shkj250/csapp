# Malloc Lab · 用不变量管理内存

[总路线](../README.md) · [工具箱](../learning/TOOLBOX.md) · 原始依据：[README](README)、[malloclab.pdf](malloclab.pdf)、`mm.c`、`memlib.c`。

当前 `mm.c` 是只增长堆、不复用空闲块的起始实现。这里保留所有函数，帮助你逐步建立自己的分配器。正确性、空间利用率与吞吐量三项训练都保留。

## 热身：画图后才能写指针

在纸上画连续的三个块 A、B、C，标出块头、payload、块尾（若你的设计采用块尾）、块大小与分配标志。手动释放中间块，再释放相邻块，画出操作后的布局。

过关标准：能区分 payload 大小、整个块大小、请求大小和最小块大小；能说明对齐要求作用于返回指针。当前实验要求 8 字节对齐。

## 关键知识

| 概念 / Concept | 必须明确的约定 |
|---|---|
| 元数据 / Metadata | 位于哪里，记录什么，块大小是否含元数据？ |
| 边界标记 / Boundary tag | 怎样找到物理相邻块，而非链表相邻节点？ |
| 分割 / Splitting | 剩余空间是否足以形成一个合法空闲块？ |
| 合并 / Coalescing | 两侧分配状态共有四种组合，怎样更新结构？ |
| 空闲链表 / Free list | 每个空闲块出现几次，前后链接是否一致？ |
| 一致性检查 / Heap checker | 在错误传播前发现第一个不变量破坏 |

本实验的 `mem_sbrk` 通过提供的 memlib 管理模拟堆；不要用系统 malloc 等替代自己的分配器。数据结构和全局变量约束以原 PDF 为准。

## 阶段 1：理解基线与工具

```sh
make
./mdriver -V -f short1-bal.rep
./mdriver -V -f short2-bal.rep
```

需要 32 位编译环境。先读 tiny trace 格式与驱动输出，把请求映射到 `mm_malloc`、`mm_free`、`mm_realloc`，观察为什么只增长堆即使部分结果正确，空间利用率仍然不足。

过关标准：能解释初始实现的局限，知道 `mem_sbrk` 失败返回 `(void *)-1`，与返回 NULL 不同。

## 阶段 2：先建最简单的可复用分配器

先确定块表示与初始化，再实现搜索、分割、释放和合并。隐式空闲链表可以作为第一版，待正确后再研究显式或分离空闲链表。

解题时按讲义编写自己的堆检查器。建议检查：地址在堆内、payload 对齐、块大小合法、块不重叠、所选表示的头尾一致。若采用立即合并，相邻空闲块不应留下未合并状态。若有空闲链表，再检查遗漏、重复、循环和双向链接。

每次堆操作后检查；把分割和四种合并情况分别缩成最小 trace。最终计时前去掉热路径中的调试检查调用，保留检查器供排错。

过关标准：两个小 trace 通过；自己的最小操作序列也满足不变量。不要一次从基线跳到复杂分离链表。

## 阶段 3：realloc 的语义与可靠性

先完成简单且正确的策略，再研究原地扩张。按讲义分别处理 NULL、零大小、缩小、扩张、分配失败；保留长度为新旧大小较小者的数据。分配新块失败时，原块不能先被释放。

过关标准：用有规律的字节内容验证保留的数据，不只比较返回地址；NULL 与零大小符合本实验讲义语义；失败路径不损坏原状态。检查旧起始实现并不意味着它已覆盖所有边界。

<details>
<summary>提示 3：realloc 后内容变了</summary>

检查复制长度使用的是 payload 容量还是包含元数据的块大小；检查读取的旧大小字段是否仍然有效；如果移动或合并了块，核对源区域是否仍完整。

</details>

## 阶段 4：用完整负载优化

当前仓库只有两个小 trace，`config.h` 的默认完整测试路径指向历史 `/afs/...`。两个小 trace 不能支撑完整性能结论。取得与课程匹配的全部 trace 后，设它们所在目录，例如 `traces/`：

```sh
./mdriver -V -t traces
```

这里 `traces/` 是需要你准备的完整测试目录，当前未提供；不得用复制小 trace 冒充正式集合。`-t` 配合默认 trace 名称；单独文件可使用 `-f` 指定路径。

每次只改变搜索策略、大小类别、分割阈值或 realloc 策略中的一个，比较利用率和吞吐量，不能只优化其中一项后宣称全面改善。

## 完整验收与进阶

完整 trace 集正确性全部通过，满足对齐与接口约束，原性能评价达标；单独检查讲义边界与堆不变量。没有完整集合时，记录“完成小 trace 验证，完整验收待材料”，不把它称为毕业。

进阶：构造使 first-fit 表现差的请求序列；解释立即/延迟合并的取舍；证明链表节点与空闲块是一一对应。优秀分配器不仅跑得快，还要有能定位结构损坏的证据。
