# Data Lab · 从位模式开始思考

[总路线](../README.md) · [工具箱](../learning/TOOLBOX.md) · 原始依据：[README](README)、[datalab.pdf](datalab.pdf)、`bits.c` 每题注释。

本实验练的是“在严格限制下表达逻辑”。本仓库已有部分解答和双语注释；保留它们，尚未完成的函数仍由你完成。指南中的学习顺序不改变题号、操作上限或允许的运算符。

## 热身：先把 32 位缩成 4 位

在纸上写出 4 位补码的所有值，圈出 0、-1、最小负数、最大正数。对 `0101` 和 `0011` 手算 `&`、`|`、`^`、`~`，取反仍限制在 4 位。

过关标准：能分清 `!x` 的布尔结果和 `~x` 的逐位结果；能解释为何最小负数没有同位宽的正数对应。热身的 4 位模型只用于理解，提交题按 32 位假设执行。

## 先学这几个知识点

| 概念 / Concept | 你需要掌握的动作 |
|---|---|
| 真值表 / Truth table | 先逐位列出输入输出关系，再组织表达式 |
| 补码 / Two's complement | 写出符号位的权重，而不只记公式 |
| 掩码 / Mask | 区分“布尔 0/1”和“全零/全一位模式” |
| 溢出 / Overflow | 分清数学结果与固定宽度位模式；比较时先考虑异号 |
| 浮点编码 / Floating-point encoding | 分开符号位、8 位指数、23 位 fraction；偏置为 127 |

## 阶段 1：单个位到整个位模式

学习顺序：`bitXor` → `tmin` → `negate` → `allOddBits` → `isTmax`。先推导，再看你已经写过的实现。

每题写三件事：目标位关系、合法运算符、边界。`allOddBits` 的位编号从最低位 0 开始；`isTmax` 要主动寻找“也满足某个中间性质”的假阳性。

```sh
make btest
./dlc bits.c
./btest -f bitXor
./btest -f allOddBits -1 0xAAAAAAAA
```

过关标准：这一组逐题通过；能解释每个中间变量对应哪些位。`dlc` 检查规则，`btest` 检查结果，两者都需要。

<details>
<summary>提示 1：表达式想不出来时先观察什么</summary>

不要直接在 32 位十六进制里猜。对一对输入位列四行真值表，再问目标输出能否用允许的门组合。掩码题先在 8 位里画出目标位置，再扩展到 32 位。

</details>

<details>
<summary>提示 2：过了常规值却错在边界</summary>

把 0、-1、Tmin、Tmax 分开代入每个中间式。某个等式可能同时成立于两个特殊值；你需要证明筛选条件排除了不该接受的值。这里不提供最终筛选式。

</details>

## 阶段 2：把判断变成位运算

学习顺序：`isAsciiDigit` → `conditional` → `isLessOrEqual` → `logicalNeg`。

先用普通 C 或伪代码写规格，再翻译为合法表达式；普通 C 的草稿放独立笔记或练习文件，不放到提交文件中。比较题分别分析同号和异号；选择题先问如何从真假生成“覆盖所有位”的选择信息。

自己设计测试：ASCII 区间两端及各自外侧一个值；选择题的 `x=0` 和多个非零值；比较题的相等、异号、极值；逻辑非的零、正数、负数和 Tmin。

过关标准：这四题逐题通过；能给出直接通过相减比较大小会失败的输入；能解释 `logicalNeg` 为什么覆盖 Tmin。

<details>
<summary>提示：别把布尔值当成完整掩码</summary>

在纸上把 1 写成 32 位，检查它实际控制了几位。比较时先列“x、y 是否异号”的分支表，再决定哪些分支可以安全使用差值的符号。

</details>

## 阶段 3：数位宽，而不是猜位宽

目标：`howManyBits`。先手算 0、-1、1、-2、Tmin、Tmax 需要的补码位数，注意题目包含符号位。热身：在 8 位纸面模型里找某个非零位模式最高的 1。

过关标准：能解释正数和负数为何需要不同的初始分析；逐题通过后，能说明一系列缩小搜索范围的步骤为何覆盖所有位。

<details>
<summary>提示：怎样降低搜索复杂度</summary>

观察“高半部分是否有目标位”能排除多大的范围；把同一问题从 32 位缩成 16 位、8 位。先设计搜索过程，再核对所有移位量是否在题目允许范围内。

</details>

## 阶段 4：把浮点数当编码处理

学习顺序：`floatScale2` → `floatFloat2Int` → `floatPower2`。浮点题规则与整数题不同，仍然禁止浮点类型、强制转换和函数调用；逐题看注释。

先列分类表：零、非规格化数（denormalized）、规格化数（normalized）、无穷、NaN。规格化值为 `(-1)^s × (1.f) × 2^(e-127)`；非规格化值为 `(-1)^s × (0.f) × 2^-126`。

```sh
make fshow
./fshow 0x3f800000
./fshow 0x00000001
./fshow 0x00800000
./fshow 0x7f800000
./btest -f floatScale2
./btest -f floatFloat2Int
./btest -f floatPower2
```

第一条表示 1.0；后三条让你观察最小非规格化数、最小正规格化数和正无穷。工具是观察编码，不是替你实现函数。

过关标准：为每一分类写处理理由；检查非规格化到规格化、有限到无穷、转换截断和越界。转换题的越界返回值严格按 `bits.c`。

<details>
<summary>提示：不要只对指数做加减</summary>

指数全零和全一有特殊含义，隐含最高位也不总是 1。先分类，再考虑数值移动；每次移位前写出可能的指数范围。

</details>
